## Claims need evidence

`claims-guard.mjs` compares your final answer with the action log of the session, subagents included, and blocks unsupported claims once.

- "Tests pass" needs a test run after the last edit without errors.
- "Build and lint are clean" needs those commands run.
- "Deployed" or "pushed" needs a push or deploy command.
- "Read" or "checked" a named file needs that file opened.
- A number with a unit next to a speed or growth word must appear in command output.

Write what you did not verify as "not verified" or "estimate from X and Y".
